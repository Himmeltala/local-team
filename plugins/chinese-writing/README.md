# chinese-writing

中文表达与理解规范插件：约束助手写中文的方式，以及读中文需求的方式。

## 组件

| 组件 | 类型 | 作用 |
|---|---|---|
| `chinese-writing` | 技能 | 中文产出八条（介词、量词、关联词、语序、术语、符号代字、中英空格）；读中文需求的歧义确认 |
| SessionStart 提醒 | 钩子 | 会话开始时注入中文约定 |

## 安装

市场源是 GitHub 上的 `Himmeltala/local-team` 仓库，对应工作副本 `~/projs/自用项目/local-team`：

```bash
claude plugin marketplace add Himmeltala/local-team
claude plugin install chinese-writing@local-team
```

改完插件内容后需要重启会话生效（钩子在会话启动时加载）。

## 使用

技能会在写注释、写文档、写提交信息时自动触发，也可以显式调用：

- 说"这句话中文不通""缺介词""符号别当代替" —— 触发规则
- `/chinese-writing:chinese-writing` —— 显式走一遍规则

## 核心约定速览

**两套标准**：落盘产出（注释、提交信息、文档）规范优先，介词、量词、关联词写全；对话回复精简优先，允许电报体、允许省介词。两条例外——**禁符号代字**与**中英混排空格**——对话回复也照办。

**禁符号代字**：`+ - * / & = → < > ≥` 写进中文句子就要写成词（加、和、或者、等于、变成、小于、约）。代码块、命令、路径、正则、字符串字面量与注解值里的符号是数据，原样保留。

**介词写全**：把、被、对、向、从、给、用、按、比、为，一个都不省。

**关联词配对**：因为…所以、虽然…但是、不但…而且、只有…才、如果…就。不单用一半，不叠用。

**量词与单位不省**：写"3 个文件""500 毫秒"，不写"3 文件""500ms"。

**语序按中文**：状语前置，定语在前带"的"。不写英式后置长定语。

**中英混排加空格**：中文与英文、数字之间留一个半角空格，例如 `你好 nihao`、`共 3 个文件`。

**读中文需求**：中文常省主语与宾语，遇歧义先复述确认；一词多义（接口、清理、提交）先对齐；否定词漏读代价最大；一次只问一个问题。
