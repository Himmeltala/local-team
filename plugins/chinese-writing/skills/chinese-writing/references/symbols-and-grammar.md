# 符号与语法细则

`SKILL.md` 里那八条的完整对照与例外。判断顺序：先看这个符号是不是出现在代码、命令或数据里，是就原样保留；不是就按下表写成词。

## 一、符号代字对照

| 符号 | 想表达的意思 | 写成 |
|---|---|---|
| `A + B` | 相加 | `A 加 B` |
| `A + B` | 并列 | `A 与 B`、`A 和 B` |
| `A - B` | 相减 | `A 减 B` |
| `A * B` | 相乘 | `A 乘以 B`、`A 的 B 倍` |
| `A / B` | 相除 | `A 除以 B` |
| `A / B` | 二选一 | `A 或 B` |
| `A / B` | 单位 | `A 每 B`（`100 条每秒`） |
| `A → B` | 变换 | `从 A 变成 B`、`把 A 转成 B` |
| `A → B` | 传递 | `A 传给 B`、`A 映射到 B` |
| `A = B` | 相等 | `A 等于 B` |
| `A = B` | 赋值或设置 | `把 A 设为 B` |
| `A > B` `A < B` | 比较 | `A 大于 B`、`A 小于 B` |
| `A ≥ B` | 比较 | `A 不小于 B`、`A 大于或等于 B` |
| `A & B` | 同时满足 | `A 与 B`、`A 且 B` |
| `A ~ B` | 范围 | `从 A 到 B` |
| `A | B` | 可选 | `A 或 B` |
| `√` `×` `★` `✓` | 判断与装饰 | 写成文字，或整句删掉 |

同一行里符号连着出现时，逐个展开，不要留一半：`KB → GB, 1/1000` 写成"由 KB 换算成 GB，比例是千分之一"。

## 二、介词：哪些不能省

中文靠语序和介词分工。省掉介词以后，读者得靠猜补出成分关系，这是电报体最伤的地方。

| 介词 | 管什么 | 例子 |
|---|---|---|
| 把 | 处置的对象 | `把 regionId 转成 orgCode` |
| 被 | 受动 | `被钩子拦下` |
| 对 | 针对的对象 | `对提交信息做校验` |
| 向 | 方向与对象 | `向用户确认` |
| 从 | 起点 | `从工作副本里读路径` |
| 给 | 受益或传递 | `给接口补一个字段` |
| 用 | 工具与手段 | `用 svn diff 看改动` |
| 按 | 依据 | `按团队规范写注释` |
| 比 | 比较 | `比上一版少 20 行` |
| 为 | 目的与原因 | `为避免误拦，先查工作副本状态` |

常见错误是把介词连同主语一起省掉：`落后就别提交` 缺少主语与条件介词，落盘产出里要写成"如果工作副本落后于服务器，就不要提交"。

## 三、关联词配对表

| 前半 | 后半 | 常见错法 |
|---|---|---|
| 因为 | 所以 | `因为…因此`（叠用）、只写后半 |
| 虽然 | 但是 | `但是` 甩到句末（"他改了，但是"） |
| 不但 | 而且 | 写"不但…也" |
| 只有 | 才 | 写"只有…就" |
| 如果 | 就 | 只写前半 |
| 即使 | 也 | 写成"即使…但是" |
| 无论 | 都 | 写成"无论…也" |

关联词位置也有讲究：前后分句主语相同时，关联词放主语后面（"他不但改完了，而且提交了"）；主语不同时，关联词放主语前面（"不但他改完了，我也提交了"）。这条只在长句里才会出错，短句别硬套。

## 四、量词与单位

- 量词不能省：`3 个文件`、`5 条记录`、`2 个接口`。
- 单位用中文：`500 毫秒`、`2 兆字节`。英文缩写只在代码、命令、表格表头里用。
- 数字与量词之间、数字与中文之间留空格：`共 127 处`、`约 990 个 Java 文件`。
- 百分数与比例写中文：`百分之二十`，或在表格里保留 `20%`。

## 五、语序

中文的状语在动词前，定语在名词前带"的"。

| 英式语序 | 中文语序 |
|---|---|
| 加一行，在配置文件里 | 在配置文件里加一行 |
| 提交被拦下，因为工作副本落后 | 因为工作副本落后，所以提交被拦下 |
| 一个返回 JSON 的接口，统计用 | 一个统计用的、返回 JSON 的接口 |

倒装只在前后文已经铺好条件时用，不要拿它当省字的办法。

## 六、中英混排空格

- 中文与英文之间加一个半角空格：`用 svn update 拉取`、`见 comment-style 插件`。
- 中文与数字之间加一个半角空格：`共 3 个文件`、`127 处`。
- 英文与英文标点之间不加空格：`feat: xxx`。
- 标点用全角，紧贴中文：`先更新，再提交。` 不写 `先更新 , 再提交 .`。
- 成对的括号跟着内容走：中文语境用全角括号（像这样），代码与参数用半角括号 `(String name)`。
- 反引号内的内容原样，前后按中英混排加空格：`` 用 `svn status` 看状态 ``。

## 七、例外：哪些不算符号代字

下面这些位置里的符号是数据或语法，一个字都不改：

- 代码块、行内代码、命令、路径、正则、文件名。
- 字符串字面量与注解值：`remark = "在线→离线"`、`@ApiOperation(notes = "市→县")`。那里的箭头、加号是给程序或接口文档看的。
- 表格里的表头与枚举值：`| + | - |` 这类对照表本身就在讲符号。
- 数学与公式语境：`O(log n)`、`x² + y² = r²`。

判断标准：这句话里的符号是**说给人听的**，还是**给程序读的**。前者写成词，后者原样留。
