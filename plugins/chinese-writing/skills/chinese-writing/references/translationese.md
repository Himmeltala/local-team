# 翻译腔：不逐词照搬英文

中文的词、短语、句式有自己的搭配与语气，和英文不是一对一。照字面把英文说法搬过来，就成了翻译腔——语法没错，但汉语里没人这么说。

判断办法只有一条：**先想汉语里这件事怎么说，再落笔；写完念一遍，像中国人会说的话吗？** 不像就换。一个英文词往往对应好几种汉语说法（`get` 能译成"拿到、变得、懂了、遭到"），咬住一个译法不放，就是翻译腔的来源。

## 词汇与短语

| 英文原话 | 翻译腔 | 汉语这么说 |
|---|---|---|
| oh no | 哦不 | 糟了、坏了、不好 |
| you know | 你知道的 | （省略）、就是说 |
| I see | 我看见了 | 明白了、原来如此 |
| make sense | 让它有意义 | 说得通、有道理 |
| no way | 没有路 | 不可能、想都别想 |
| that's a good question | 这是一个好问题 | 问得好（或直接回答） |
| take care | 拿着照顾 | 保重 |
| for your information | 为了你的信息 | 顺带说一句 |
| as soon as possible | 尽快（算通顺） | 尽快、立刻办 |
| have a nice day | 有一个好的一天 | 祝你今天顺利 |

语气词与称呼最容易露馅：英文的 `dear`、`sir` 直译成"亲爱的""先生"放进中文对话很别扭；`hello` 在汉语里更多是"你好""在吗"，不是"喂"。

## 句式

| 英文句式 | 翻译腔 | 汉语这么说 |
|---|---|---|
| a better solution | 一个更好的解决方案 | 更好的方案 |
| in the case of X | 在 X 的情况下 | 如果 X、X 时 |
| when X happens | 当 X 发生的时候 | X 发生时 |
| it is worth noting that … | 值得注意的是 … | 直接说那件事 |
| because of the reason that … | 由于 … 的原因 | 因为 … |
| the problem was solved | 问题被解决了 | 问题解决了 |
| we made a decision | 我们做出了一个决定 | 我们决定 |
| conduct an investigation | 进行调查 | 调查 |
| give consideration to | 给予考虑 | 考虑 |
| X and Y | X 和 Y（逐字堆连接词） | 视情况用顿号、分句或意合 |

三条高发毛病：**"一个"当冠词用**（英文的 a/an 在汉语多数时候不译）、**被动句当默认**（汉语习惯主动，能用主动就不用"被"）、**名词化**（"进行…的处理""做出…的决定"换成动词）。

代词也常出问题：英文的 it / they 到了汉语，指代不清时宁可重复名词或干脆省略，不要一路"它、它们"到底。

## 例外

- **技术术语、协议名、产品名照通行译法或原文**：`callback` 译"回调"，不是"回头叫"；`Kubernetes` 可以写原文。这类不是翻译腔，是为了准确。
- **外来术语已有惯用译法时不要另造**：`缓存`、`线程`、`句柄` 都是定译，别为了"更像中文"改成别的词。
- **引用他人原文时保持原样**，包括里面的翻译腔。

判断标准与符号代字那条同源：这句话是说给人听的，还是给程序读的。给程序读的（代码、命令、字段名）原样保留，说给人听的按汉语习惯写。
