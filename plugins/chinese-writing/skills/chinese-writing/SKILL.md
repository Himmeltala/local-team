# 中文表达与理解

## 两套标准

| 场合 | 标准 |
|---|---|
| 落盘产出：注释、提交信息、文档、README | 规范优先。介词、量词、关联词写全，禁符号代字 |
| 对话回复 | 精简优先。允许电报体，允许省介词 |

三条例外，对话回复也照办：**禁符号代字**、**中英混排空格**、**禁翻译腔**。省掉的介词读者能补回来，`a → b`、"你好nihao"和"哦不"不能。

细则见 `references/symbols-and-grammar.md` 与 `references/translationese.md`；读中文需求的做法见 `references/reading-chinese.md`。

## 篇幅标准

篇幅按产出物定，不按心情定。数值只有一份，就写在这里：

| 产出物 | 篇幅 |
|---|---|
| 对话回复 | 精简优先，允许电报体，允许省介词 |
| 代码注释 | 一律一行，最多两行；例外（Vue 文件头六字段块、功能性指令、注解值）见 `comment-trimming` 插件 |
| 提交信息 | 只有一行，格式见 `commit-guarding` 插件 |
| 文档 | 不限长，但一句一义，不注水 |

一句信息写不完，说明它该挪进命名、常量或文档，不要在原处加长。其它插件不再另写一份长度数值，只指认本表。

## 落盘产出九条

1. **符号不代字。** `+ - * / & = → < > ≥ ≈ ~` 写进中文句子就要写成词：加、和、或者、等于、变成、小于、约。代码块、命令、路径、正则里的原样保留。
2. **介词写全。** 把、被、对、向、从、给、用、按、比、为，一个都不省。
3. **关联词配对。** 因为…所以、虽然…但是、不但…而且、只有…才、如果…就。不单用一半，不叠用（"因为…因此"），不把"但是"甩到句末。
4. **量词与单位不省。** 写"3 个文件""500 毫秒"，不写"3 文件""500ms"（代码与命令除外）。
5. **语序按中文。** 状语前置（"在配置文件里加一行"），定语在前带"的"。不写英式后置长定语，不写"能跑通的话，如果…"这类倒装。
6. **术语统一。** 一个概念从头到尾一个词，不换同义词。团队术语照原样：工作副本、提交信息、虚谷库。
7. **一句一义。** 一句话说完一个意思。逗号串到底的长句断开，不靠分号续命。
8. **中英混排加空格。** 中文与英文、数字之间留一个半角空格：`你好 nihao`、`123 你好`、`共 3 个文件`、`用 svn update 拉取`。标点用全角，紧贴中文，不与空格混用。
9. **不写翻译腔。** 中文的词与句式和英文不是一对一，照字面搬英文说法就成了翻译腔（`oh no` 直译成"哦不"，汉语里没人这么说，该说"糟了"）。先想汉语里这件事怎么说，再落笔；写完念一遍，像中国人会说的话吗。对照表见 `references/translationese.md`。技术术语与产品名照通行译法或原文，不受此条影响。

## 反例速查

| 反例 | 改写 |
|---|---|
| `regionId → orgCode` | `regionId 映射到 orgCode` |
| `A + B` | `A 加 B` 或 `A 与 B` |
| `可用/不可用` | `可用或不可用` |
| `3 文件，500ms` | `3 个文件，500 毫秒` |
| `配置→生效` | `改完配置后生效` |
| `你好nihao` | `你好 nihao` |
| `哦不`（oh no 直译） | `糟了` |
| `一个更好的解决方案` | `更好的方案` |
| `我们做出了一个决定` | `我们决定` |

完整对照与例外见 `references/symbols-and-grammar.md` 与 `references/translationese.md`。

## 与其它技能的分工

符号规则、翻译腔与篇幅数值都以本技能为准，`comment-trimming` 插件只管注释特有的部分（哪些注释该删该留、字符串字面量与注解值是数据、前端 eslint 的符号清单）。两处不要各写一份。
