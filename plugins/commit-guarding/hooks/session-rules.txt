版本控制约定（commit-guarding 插件，全程适用）：

- 先认清是 svn 还是 git：目录下有 .svn 就是 SVN，有 .git 就是 git，两套不混用。动手前先 svn info 或 git status -sb 确认。
- 自用项目各仓库直接在 main 上提交，不建分支、不建 PR、不写 Co-Authored-By 尾注。
- 提交前先拉最新，冲突清零才提交。落后与分叉会被本插件的 PreToolUse 钩子拦下，钩子只拦不改，update 与解决冲突由助手手工做完；推送要用户明确要求才做。
- 提交信息只有一行：<type>: <中文描述>，半角冒号加空格，前缀后面不加范围括号，一行说不清就拆成多次提交。

详见 svn-commit 与 git-commit 技能。
