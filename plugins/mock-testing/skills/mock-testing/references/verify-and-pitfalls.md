# 验证、收尾与踩坑

桩起来了、请求也发了，不等于链路通了。只有第三层通过才算测到。

## 三层验证

1. **桩活着。** 端口在听（`ss -lntp | grep <端口>` 或 `lsof -i:<端口>`），请求日志打出了这次请求，方法与路径对得上。一条都没到，先查接管，不要先怀疑桩。
2. **被测端认账。** 被测端日志里出现该链路的关键字，顺序符合预期。把顺序当基线写下来，例如：收到请求、校验通过、转发出站、对端已返回、状态已回写；顺序乱了说明中间某步分支没走。关键字抓这几类：入口方法名、分支日志、异常堆栈的类名、出站请求的地址。
3. **落地产物。** 核对实物：文件的内容、大小、md5；接口的状态码与返回字段；数据库的目标字段值；消息总线上的报文原文。

**界面不能当唯一依据。** 数字在跳只说明某条通道活着，判断、投递、落库可能走另一条通道；写被动观察器直接看报文，见 `examples/ws_probe.py`。

## 给静默失败加观测点

链路里没有日志的分支最危险：判断不成立、catch 吞掉异常、提前 return，三种都不留痕。跑测之前扫一遍相关代码找到它们，临时加打印并带上参与判断的原始值，跑完删掉；只打一句"跳过"没用。

## 故障档与边界值

把故障与边界做成开关，逐档跑：成功、对端返回失败（业务错误码）、对端返回参数非法（带错误详情）、对端不返回（挂起，配合把被测方的超时阈值临时调小，否则等不起）、对端连不上（桩不起）、边界值（空值、0、负值、超长、格式非法）。边界值靠桩的状态设置构造，别改被测代码。

## 预期噪音

本地环境固有、不是故障的报错，跑之前先列出来，否则下一轮排查会当成问题：二进制协议通道连不上（本地没有对端）、云端或第三方不可达（启动与定时任务里的推送失败日志）、缺硬件（摄像头、串口、扫码枪）、鉴权拦截（本机不带头调用返回 401）。结论里写清哪条日志属预期、判据是什么。

## 收尾还原清单

- [ ] 停掉本次起的桩与后端进程，端口已释放（`ss -lntp` 确认）。
- [ ] 启动脚本里没有残留测试用的覆盖参数。
- [ ] 改过的配置文件已还原，共享盘与生产配置文件 md5 未变或改动是用户要求的。
- [ ] 临时加的打印已删除；临时生成的数据目录、缓存、日志按需清理或保留说明。
- [ ] 结论里写清：测通了哪几层、哪些没测、哪些是预期噪音。

## 结论写法

按层给结论，不要笼统说"通了"：

```
环境：桩 A（端口 x）替服务甲，桩 B（端口 y）替服务乙，后端跑真实 dev profile。
第一层：通过，桩收到 3 次请求，路径符合契约。
第二层：通过，日志顺序为 …。第三层：通过，产物为 …。
故障 5 档中 4 档符合预期，挂起档未测，原因是…。未覆盖：末段依赖远端。预期噪音：…
```

## 踩坑清单，按症状查

**桩起不来**

- **端口已被占用。** 先查端口，确认不是自己上次没停干净；起停脚本加端口预检，见 `examples/sim_run.sh`。
- **起来的是别人的进程。** 就绪探测不能只看端口有没有人听，要比对刚起的进程号与端口上的进程号。

**请求到了但结果不对**

- **路径前缀被代理剥掉。** 确认代理的 rewrite，按剥完之后的路径注册路由。
- **字段名或格式不一致。** 拿真实报文逐字段比对，见 `method.md`。
- **对端按序号去重。** 第二次同样的包不生效时，每次换个序号或标识，别拿同一个包反复测。
- **单连接服务互相顶替。** 脚本一跑界面就断时，确认服务端是不是只保留最新连接，是就两边轮流开。
- **系统代理拦掉本机请求。** 连 `127.0.0.1` 却报代理错误时，显式关掉环境代理（Python 的 `requests` 用 `sess.trust_env = False` 加空 `proxies`）。

**链路静默失败**

- **成功码与实际不符。** 桩返回成功、被测方判的是包体业务码时，把被测方的成功判据从代码里找出来。
- **判断分支提前 return。** 日志里只有入口那一行时，临时加打印，把判断依据的实际取值打出来。
- **异常被吞。** 什么都不发生也没有报错时，查相关 catch 块，临时加打印再跑。

**结果对但不可信**

- **产物比源码旧。** 改了代码却没有任何变化时重新构建；产物里缺资源文件也是常见情况。

**脚本自身的坑**

- **管道提前退出导致误判。** `cmd | grep -q` 会把 `cmd` 的失败误判成"内容里没有这一项"；先把输出取到变量再匹配。
- **用固定等待判断就绪。** 改成轮询探测端点或日志关键字，配超时上限。
- **清理不干净。** 写 pid 文件，`stop` 子命令按 pid 停，并核对端口已释放。
